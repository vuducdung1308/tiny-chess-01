A 4 KB Python chess engine: a Stockfish-computed trial-0 variant table over a fallback alpha-beta engine (0x88 board, PVS, transposition table, quiescence, null-move pruning, LMR, check extension). Practice trial-0: Elo 2112, 6-0-0, all wins by checkmate.

## Run it

```sh
MAKEFUN_ENV_URL=<game-server-url> python3 main.py
```
